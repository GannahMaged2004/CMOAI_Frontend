# CMO.AI 🚀

An AI-powered marketing platform that transforms business ideas into structured marketing strategies.

## ✨ Features

- AI-driven brand coaching
- Market planning and strategy generation
- Smart content calendar
- Campaign management dashboard
- Performance analytics

## 🛠 Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- ShadCN UI
