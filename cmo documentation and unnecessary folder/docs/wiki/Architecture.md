# Architecture

## High-level structure

- `frontend/`: React + TypeScript + Vite application
- `app/`: FastAPI backend with modular routers, schemas, models, and services
- `alembic/`: migration history
- `uploads/`: generated or uploaded assets

## Main product areas

- Authentication
- Brand and campaign management
- Market planning
- Content and calendar workflows
- Text, image, and video agent endpoints
- Analytics and dashboard summaries
