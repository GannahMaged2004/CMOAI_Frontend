# Agents

## Included agents

- Orchestrator
- Market planner
- Brand coaching
- Calendar support
- Text agent
- Image agent
- Video agent
- Analytics support

## Notes

- The image agent supports fallback image output when external image providers are not configured.
- The video agent supports fallback planning/script output when the live provider stack is unavailable.
- For demos and future-work discussions, present the orchestrator first, then show how it connects planner, brand, text, image, video, calendar, and analytics inside one dashboard flow.
