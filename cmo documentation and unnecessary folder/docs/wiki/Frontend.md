# Frontend

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components

## Key areas

- Dashboard workspace
- Market Planner
- Brand coaching
- Calendar
- Text agent
- Image agent
- Video agent
- Analytics

## Development

```bash
cd frontend
npm install
npm run dev
```
